A new way to think with your local agents

Solipsist is a markdown editor for planning, research and writing. Your agents work inside the page, on your machine, with the models you already use.

How it works

Solipsist runs in the folder your files are in. Its agents are Pi, an open-source coding agent, built in: you don't need to install it, and an OpenRouter key is enough to start. If you already use Pi, it works here with the same models, logins, skills and connected tools.

Like Pi in a terminal, an agent can run commands on your computer. Solipsist doesn't sandbox them.

What you can ask for

Plans, research, reports and notes. The agent looks things up, drafts and draws, and you decide what goes in the page.

Save a task as a button

Keep any task as a button. Press it and the agent does the work again and updates the text in place.

Or put it on a schedule, from every minute to once a day. While Solipsist is running, it updates the page whether you have it open or not.

⏱ every day

Research questions, answered in the page

Ask a question the way you would ask a colleague. The agent searches, reads and writes up what it found, right under your question.

Each task gets its own agent, so several can work while you keep writing.

Trauma and belief

What does recent research say about how trauma changes religious belief?

It goes both ways. Some people's faith deepens after a trauma and others lose it, and which way depends more on how they coped than on what happened.

What should I ask in my interviews?

  • Did your beliefs change afterwards, and how soon?

  • Who did you talk to about it?

  • What do you no longer believe?

Page review

An agent reads the whole page and leaves questions in the margin, wherever something is unclear, missing or doesn't add up.

It changes nothing in your text. Open a question to see the reasoning, dismiss it, or ask more.

We move to $12 per seat in January, and existing teams keep their price for a year.

Most teams will not notice the change, since they already pay for more seats than they use.

Your pages are markdown files

Every page is a markdown file in your own folder, and what the agent adds is ordinary text once you accept it. Copy a page into Google Docs or any editor like it: headings, lists, tables, links and pictures stay as they were.

And the rest

  • Any model you already pay for

    OpenRouter, a subscription you already have, or a model running on your own computer. Choose one for each page.

  • Rewrite anything

    Select some text and say what you want: shorter, friendlier, as a table. The old and new text sit side by side until you choose.

  • Chat with the agent

    Talk to the agent that made a suggestion and it revises the result. There is also a chat about the whole page.

  • Ask about a passage

    The answer appears in a card beside it. Nothing is added to the page.

  • Instructions you can edit

    Everything the agents are told is written down where you can read it and change it.

  • Spending limits

    Daily and monthly caps stop new runs when they are reached. The defaults are $5 a day and $50 a month.

  • A real editor

    Headings, lists, tables, images and links, with the usual shortcuts. Vim keys if you want them.

  • Private

    No account, no analytics, no telemetry. Nothing about you or your use is sent anywhere. A task sends the text it needs to your model, and to any tools you connected.

Open a folder you already have

You need Bun. Solipsist lists the markdown files it finds in the folder. Pick the ones to work on.

$ git clone https://github.com/pulkitsharma07/solipsist ~/solipsist
$ cd ~/solipsist && bun install
$ cd ~/my-notes && bun ~/solipsist/src/index.ts

Then open localhost:3000 and connect a model: an OpenRouter key, or a login you saved in Pi. Read the code on GitHub
