```text
bun ~/solipsist/src/index.ts [options]

  --config <file>   Use this settings file (default: ./solipsist.yaml, then ~/.config/solipsist/config.yaml).
  --print-config    Print every setting, its value and where it came from, then exit.
  --version         Print the version and exit.
  --help            Print this and exit.
```

Everything else is a setting, in `solipsist.yaml` or the environment. See
[Configuration](/docs/reference/configuration/). An unknown flag is an error. It isn't passed on to anything.

## Seeing what's in effect

`--print-config` prints each setting's value and where it came from (`default`, `file` or `env:NAME`). In the browser,
the **Loaded settings** tab in settings (the gear icon) shows the same list for the running server. Keys only ever
show as `set`.

## The terminal view

While the server runs, the terminal shows what each page's agents are doing and what they cost. Set `SOLIPSIST_TUI=0`
to get plain log lines instead. Stopping the server (<kbd>Ctrl</kbd>+<kbd>C</kbd>) stops every agent and puts the
requests they were working on back to waiting.
