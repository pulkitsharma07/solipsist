On macOS or Linux:

```bash
curl -fsSL https://solipsist.sh/install | sh
```

On Windows, in PowerShell:

```powershell
irm https://solipsist.sh/install.ps1 | iex
```

The installer downloads the release for your system (macOS and Linux on Intel or ARM, Windows x64; Linux needs glibc,
so not Alpine), checks it against the release's `SHA256SUMS`, and puts one `solipsist` program where you choose. On
macOS and Linux it asks: just for you (`~/.local/bin`, no sudo, the default), for everyone (`/usr/local/bin`, with sudo
if it needs it), or this folder only (run it as `./solipsist`). Run without a terminal (in CI, say), it asks nothing
and installs just for you. On Windows it goes in `%LOCALAPPDATA%\solipsist`. It needs no Bun, and touches nothing
outside that folder. If the folder isn't on your `PATH`, it offers to add it to your shell's startup file. If no model
is connected yet (no OpenRouter key, no login saved in Pi), it says how to [connect one](/docs/start/connect-a-model/).
To check what you got:

```bash
solipsist --version
```

Then start it **in the folder you want to write in**:

```bash
cd ~/my-notes && solipsist
```

Open [localhost:3000](http://localhost:3000). To use a different port, set `server.port` (or `PORT`).

## Picking the files

The first time you start it, Solipsist lists the markdown files it finds in that folder. If there are none, it offers
to start a new page instead: give it a name (`notes.md`) and press Create page.

<Shot name="setup-dialog" title="Choose your files" alt="The Choose your files dialog: the markdown files found in the folder, each with a checkbox" caption="The first launch: pick the files to work on." />

Pick the ones you want to work on. Each one is copied into `.solipsist/pages/` and opened from there. Your originals
aren't touched until you [sync](/docs/guides/files-and-sync/).

By default it only looks in the folder itself (`*.md`). To include subfolders, add patterns to a `solipsist.yaml` in
the same folder:

```yaml
md_search_paths:
  - "*.md"
  - docs/**/*.md
```

It never lists files in dot-folders, in `node_modules`, or anything git ignores.

## Command line

```text
solipsist [--config <file>] [--print-config] [--version] [--help]
```

Everything else is a setting. See the [command line reference](/docs/reference/cli/) and
[configuration](/docs/reference/configuration/).

## Updating

Run the install command again: it replaces the program with the latest release. Restart the server afterwards. To
install a particular release, set `SOLIPSIST_VERSION` (`curl -fsSL https://solipsist.sh/install | SOLIPSIST_VERSION=0.2.0 sh`),
and `SOLIPSIST_INSTALL_DIR` to install somewhere else. To uninstall, delete the program: your pages are never touched.

## Running from source

If you would rather run the code, you need [Bun](https://bun.sh) and a clone of the repository:

```bash
git clone https://github.com/pulkitsharma07/solipsist ~/solipsist
cd ~/solipsist && bun install
cd ~/my-notes && bun ~/solipsist/src/index.ts
```

Update it with `git pull && bun install` in the clone.

## Older builds

If a page was saved by a newer build than the one you're running, it opens read-only,
so an older build can't mess up a format it doesn't know.
