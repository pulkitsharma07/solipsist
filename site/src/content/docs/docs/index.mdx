Solipsist is a markdown editor for the `.md` files in a folder you already have. It has AI agents built in, but they
only **suggest** changes and never edit the page themselves. You ask for something at the cursor or about a selection,
an agent works on it in the background, and the result shows up in the page as a suggestion. You can accept it, reject
it, ask again, or chat about it.

<video src="/launch.mp4" poster="/launch-poster.jpg" controls playsinline preload="none" style="width:100%;border-radius:12px" aria-label="An 80-second film: starting Solipsist in a folder, asking an agent for the end of a sentence, accepting its suggestion, and a tour of the features"></video>

![A page in Solipsist: an agent's suggestion waits in green, with a card to accept, reject, ask again or chat](/app.jpg)

Three things are always true:

- **Your files only change when you say so.** You work on copies in `.solipsist/`, and **Sync to file** writes back
  only what you changed.
- **Agents don't edit the page.** Everything they do shows up as a suggestion. The one exception is a result you
  turn into a [button](/docs/guides/buttons/) yourself.
- **Nothing leaves your machine except what a request needs**, and that only goes to the model you connect. No
  analytics, no telemetry, no update check.
