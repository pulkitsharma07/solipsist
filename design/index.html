Design system · v0.1

The page is the product. Everything else whispers.

A small set of tokens and components for Solipsist: warm paper, one serif for the writing, one sans for the tools, and a single colour reserved for the agent. If a thing on screen isn't the writer's words or the agent's work, it should be hard to notice.

01

Principles

Five rules to settle arguments. When a new piece of UI is proposed, check it against these before picking a colour.

i.

Writing first, chrome last

The sheet uses the serif at reading size. Every bar, badge and panel uses smaller sans in secondary ink. Nothing outside the page is bolder than the page.

ii.

One accent, and it's the agent

Terracotta means "the agent is here": a pending placeholder, a live run, the chat focus ring. Green and red appear only in diffs. No blue, no filled status blocks.

iii.

Show the result, fold the work

Thinking, tool calls and token counts are real but secondary. Collapse them into one line the writer can open. The proposal is the headline.

iv.

Hairlines over boxes

Separate with space first, a 1px line second, a card last. A card inside a card is a smell.

v.

Keys are shown, not shouted

Shortcuts live in small kbd chips next to the action, never in placeholder sentences.

05

Using it

How to bring this into src/app/app.css without a big-bang rewrite.

Adopt in three steps
  1. Tokens. Paste section 1 of this file over the :root blocks in app.css. Alias the old names (--desk, --sheet, --panel) to the new ones so nothing breaks.
  2. Raw values. Replace hex colours in rules with tokens. Grep for # and rgba( in app.css; each one maps to a row in the table.
  3. Components. Rework one surface at a time: status bar, then chat modal, then margin cards. Run bun run test:ui after each.
Aliases for step 1
:root {
  --desk:  var(--bg);
  --sheet: var(--surface);
  --panel: var(--raised);
  --bar:   var(--bg);
  --bar-line: var(--line);
  --accent: var(--agent);
}

Do / don't

Do

  • Reach for --ink-2 before reaching for a colour
  • Use space to group; a line if space isn't enough
  • Put a number in .meta mono so it lines up
  • Keep one primary button per surface

Don't

  • Fill a status with a saturated background
  • Nest a bordered card inside a bordered card
  • Write a new hex value in a component rule
  • Use --agent for anything the agent isn't doing
