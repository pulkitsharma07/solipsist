Keys

Built for one hand on the keyboard. While the selector is open it takes the keys, so number keys and vim counts don't clash. It never takes focus away from the page unless you open the note.

03

Strip or ring

Both are in the demo (the toggle above the page). Same slots, same keys, same motion: a spring on open, slots appearing one after another, a highlight that slides to the active slot, and on placing, the selector shrinks into a chip at the caret.

Strip lean

  • Sits under the line like an autocomplete, so the sentence stays readable
  • Numbers read left to right, matching the number row
  • Has room for the description, kind and model
  • Small: about 330 × 150, and it never covers the caret

Ring

  • Feels most like a game weapon wheel; works well with a mouse flick
  • Covers the text you're writing around, which is what you need to see
  • The hub only has room for a short description
  • Past 8 slots it gets crowded. Keep it as a mouse-only mode?

Underneath

      
How this could map onto what exists. Plugins (gen, sel) are code: a shape, keys, phases, the protocol. Personas would be data on top: a prompt and a few settings, held in files the writer can edit and share. A persona picks a kind; it doesn't become one.

How the prompt is built (A)


system  engine's own prompt
        + protocol.md                     fixed: envelope, modes, decline. A persona can't change it.
        + persona body                    the voice and the job: "you are a research assistant…"
run     PROMPT + plugins/<kind>/prompt.md + page + the placeholder's note
limits  returns narrows checkRunReply: a persona that only answers gets <suggestion> refused, fixed in the same turn

built-ins (continue, rewrite) ship in src/plugins/<kind>/ as the fallback

  


  
  

    

      
06
Open questions

      
Each question has the answer I lean towards underneath it.

    

    

      
i.
Does ⌘. still place something by itself?
Today it's one keystroke. Adding a second key costs something for people who only ever use gen.
Lean: hold ⌘. and let go places the last-used slot, so it's still one gesture. Is 300ms the right line between a tap and a hold?

      
ii.
Do personas get their own colours?
Principle ii says the agent is the only accent. Six tints would make the margin noisy.
Lean: no. Glyph and name only; the margin note reads "Research · waiting".

      
iii.
Editing a persona while its agent is kept
A kept Pi agent has its prompt in its conversation. If the prompt changes, the agent still remembers the old one.
Lean: record a hash of the persona with the snooze; a changed hash starts a fresh agent on ask-again.

      
iv.
Per page loadouts
A novel draft and a research note want different slots.
Lean: later. Project folder overrides first; page frontmatter (slots: [continue, critic]) if people ask for it.

      
v.
Different shapes in one selector
Should a point-only persona (Figure) appear when text is selected, placed after the selection?
Lean: two separate sets, as in the demo. Fewer slots each, and each number keeps one meaning.

      
vi.
Where it opens in vim
Normal mode has no caret between characters.
Lean: g. in normal mode opens it after the cursor; in visual mode it uses the selection set.
